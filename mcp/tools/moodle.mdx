---
title: "Moodle MCP tool catalog"
description: "Every tool the Moodle MCP servers expose, with its parameters, server availability, and whether it writes to Moodle."
---

This catalog lists the 16 tools the Moodle Model Context Protocol (MCP) server provides, in the order it lists them. Descriptions are the exact text the server ships for each tool.

Fifteen tools are read-only and available on every Moodle MCP surface: the local stdio server (`moodle mcp serve`), the bridge (`moodle mcp bridge`), and the remote Worker (Bearer or OAuth). `submit` is the exception — it needs the files it uploads to sit on the same machine as the server, so it is local-only.

For how these surfaces differ, see [How MCP works](/mcp/how-it-works). For argument syntax on the CLI equivalents, see [`/moodle/reference`](/moodle/reference/index).

### home

Today's date and timezone, items due soon, unread counts and the current section of each unit. Use when the user says "dashboard". Instead: due for longer deadline lists. Input: days defaults to 14. Then: unit or item. Cost: small dashboard.

<ParamField path="days" type="integer" default="14">
  Window size in days. Minimum 1, maximum 365.
</ParamField>

Available on: local, bridge, remote. Read-only.

### due

Items due in a date window. Use when the user says "deadlines". Instead: item for submission details. Input: unit code, name, id or URL. Then: item with activity_id. Cost: up to 20 rows by default.

<ParamField path="unit" type="string | integer">
  Unit code, name, id or URL. Omit to cover every enrolled unit.
</ParamField>

<ParamField path="days" type="integer" default="14">
  Window size in days. Minimum 1, maximum 365.
</ParamField>

<ParamField path="limit" type="integer" default="20">
  Maximum rows to return. Minimum 1, maximum 200.
</ParamField>

Available on: local, bridge, remote. Read-only.

### units

Enrolled units with ids, codes and names. Use when the user says "unit names". Instead: unit for sections. Input: none. Then: unit with a name or id. Cost: small list.

<ParamField path="limit" type="integer" default="200">
  Maximum units to return. Minimum 1, maximum 200.
</ParamField>

Available on: local, bridge, remote. Read-only.

### unit

Section index and current section; section argument returns activities and files. Use when the user says "a unit or section". Instead: find for a named item. Input: unit code, name, id or URL; section number or name. Then: item or file with activity id. Cost: index about 4 KB; section about 0.5 KB.

<ParamField path="unit" type="string | integer" required>
  Unit code, name, id or URL.
</ParamField>

<ParamField path="section" type="string | integer">
  Section number or name. Omit to return the section index and the current section.
</ParamField>

Available on: local, bridge, remote. Read-only.

### find

Ranked sections, activities and discussion subjects. Use when the user says "find slides or a task". Instead: search_forums for post text; due for deadlines. Input: query and optional unit code, name, id or URL. Then: item or file with id. Cost: up to 20 rows by default.

<ParamField path="query" type="string" required>
  Search text. At least 1 character.
</ParamField>

<ParamField path="unit" type="string | integer">
  Unit code, name, id or URL to narrow the search.
</ParamField>

<ParamField path="types" type="string[]">
  Result types to include.
</ParamField>

<ParamField path="limit" type="integer" default="20">
  Maximum rows to return. Minimum 1, maximum 200.
</ParamField>

Available on: local, bridge, remote. Read-only.

### item

One activity in full: due date, status, grade, marker feedback with rubric or marking-guide rows and feedback files, attached files, quiz attempts, or a forum's latest threads. Use when the user says "submission or item detail". Instead: file for binary content; attempt for quiz answers. Input: id, same-site URL, or UNIT TASK phrase. Then: file with a file id, or attempt with an attempt id. Cost: one item.

<ParamField path="ref" type="string | integer" required>
  Activity id, a same-site URL, or a `UNIT TASK` phrase.
</ParamField>

Available on: local, bridge, remote. Read-only.

### attempt

Each question with your response, and mark, correct answer and feedback when the site shows them. Use when the user says "a quiz attempt". Instead: item for the attempt list. Input: attempt id or review URL. Then: item with quiz_id. Cost: one attempt.

<ParamField path="attempt" type="string | integer" required>
  Attempt id or the attempt's review URL.
</ParamField>

Available on: local, bridge, remote. Read-only.

### grades

Marked items; summary counts; all adds ungraded; feedback opt-in. Use when the user says "grades". Instead: item for rubrics. Input: unit; types: assign, quiz, h5pactivity. Then: offset; item id. Cost: 20 rows total.

<ParamField path="unit" type="string | integer">
  Unit code, name, id or URL. Omit to cover every enrolled unit.
</ParamField>

<ParamField path="mode" type="string" default="graded">
  `graded` lists items that have a grade, `all` adds ungraded items, and `summary` returns only per-unit counts and totals.
</ParamField>

<ParamField path="types" type="string[]">
  Activity types to include, such as `assign`, `quiz` or `h5pactivity`. Omit to include every type.
</ParamField>

<ParamField path="include_feedback" type="boolean" default="false">
  Include the marker's feedback with each item.
</ParamField>

<ParamField path="include_ungraded" type="boolean" default="false">
  Include ungraded items in `graded` mode.
</ParamField>

<ParamField path="limit" type="integer" default="20">
  Maximum rows to return across all units. Minimum 1, maximum 200.
</ParamField>

<ParamField path="offset" type="integer" default="0">
  Rows to skip, for paging.
</ParamField>

<ParamField path="graded_only" type="boolean">
  Older spelling of `mode: "graded"`. When `true`, it overrides `mode`.
</ParamField>

Available on: local, bridge, remote. Read-only.

### news

Latest announcement threads with first-post text. Use when the user says "announcements". Instead: search_forums for other discussions. Input: optional unit code, name, id or URL. Then: thread with discussion id. Cost: up to 5 announcements by default.

<ParamField path="unit" type="string | integer">
  Unit code, name, id or URL. Omit to cover every enrolled unit.
</ParamField>

<ParamField path="limit" type="integer" default="5">
  Maximum announcements to return. Minimum 1, maximum 200.
</ParamField>

Available on: local, bridge, remote. Read-only.

### thread

A discussion and a page of compact posts, with attachment links. Use when the user says "discussion posts". Instead: news for announcements. Input: discussion_id; offset and limit. Then: increase offset while posts_total exceeds returned. Cost: up to 20 posts by default.

<ParamField path="discussion_id" type="integer" required>
  Discussion id. Must be greater than 0.
</ParamField>

<ParamField path="limit" type="integer" default="20">
  Maximum posts to return. Minimum 1, maximum 200.
</ParamField>

<ParamField path="offset" type="integer" default="0">
  Posts to skip before the returned page.
</ParamField>

Available on: local, bridge, remote. Read-only.

### search_forums

Matching posts with unit and forum name maps. Use when the user says "forum post text". Instead: find for activity names. Input: query, optional unit or courseId and forumId. Then: thread with discussion_id. Cost: bounded forum scan; total covers scanned scope.

<ParamField path="query" type="string" required>
  Search text. At least 1 character.
</ParamField>

<ParamField path="unit" type="string | integer">
  Unit code, name, id or URL to narrow the search.
</ParamField>

<ParamField path="courseId" type="integer">
  Moodle course id, as an alternative to `unit`.
</ParamField>

<ParamField path="forumId" type="integer">
  Moodle forum id to narrow the search to one forum.
</ParamField>

<ParamField path="limit" type="integer" default="20">
  Maximum matching posts to return. Minimum 1, maximum 200.
</ParamField>

<ParamField path="includePostText" type="boolean" default="true">
  Include post body text in the results.
</ParamField>

<ParamField path="titlesOnly" type="boolean" default="false">
  Match against discussion titles only, not post bodies.
</ParamField>

<ParamField path="unreadOnly" type="boolean" default="false">
  Return only unread posts.
</ParamField>

<ParamField path="sortBy" type="string" default="relevance">
  `relevance` or `recent`.
</ParamField>

<ParamField path="maxForums" type="integer" default="20">
  Maximum forums to scan. Minimum 1, maximum 200.
</ParamField>

<ParamField path="maxDiscussionsPerForum" type="integer" default="50">
  Maximum discussions to scan per forum. Minimum 1, maximum 200.
</ParamField>

Available on: local, bridge, remote. Read-only.

### submit

Upload local files into an assignment; returns the receipt Moodle shows afterwards. Use when the user says "upload assignment files". Instead: item for status only. Input: assignment id, same-site URL or UNIT TASK phrase; local file paths. Then: dry_run (default) only plans; show the plan to the person, then rerun with dry_run false; final submits for grading and cannot be undone; without a draft stage saving is the submission, so it is refused unless final is true. Cost: writes to Moodle.

<ParamField path="ref" type="string | integer" required>
  Assignment id, a same-site URL, or a `UNIT TASK` phrase.
</ParamField>

<ParamField path="files" type="string[]" default="[]">
  Local file paths to upload. At most 20.
</ParamField>

<ParamField path="text" type="string">
  Online text to save. Blank lines preserve paragraphs.
</ParamField>

<ParamField path="text_file" type="string">
  Local Markdown, text or HTML file to read the online text from.
</ParamField>

<ParamField path="final" type="boolean" default="false">
  Submit for grading instead of saving a draft. Cannot be undone.
</ParamField>

<ParamField path="replace" type="boolean" default="false">
  Replace files already attached to the submission instead of adding to them.
</ParamField>

<ParamField path="accept_statement" type="boolean" default="false">
  Accept the submission statement the assignment requires, when it requires one.
</ParamField>

<ParamField path="dry_run" type="boolean" default="true">
  Plan the upload without writing to Moodle. Set to `false` to actually upload.
</ParamField>

Available on: **local only** (`moodle mcp serve`). Writes to Moodle when `dry_run` is `false`.

### file

One authenticated file: an image as image content, anything else as embedded binary, at most 16 MiB. Use when the user says "download a file". Instead: item for file choices. Input: id of a one-file activity, file or activity URL, or UNIT TASK phrase. Then: read the returned image or resource. Cost: binary content up to 16 MiB.

<ParamField path="ref" type="string | integer" required>
  Resource id, a same-site URL, or a `UNIT TASK` phrase.
</ParamField>

Available on: local, bridge, remote. Read-only.

### messages

Direct and group conversations with unread counts and the latest message. Use when the user says "messages". Instead: conversation for messages. Input: limit and offset. Then: conversation with id. Cost: 20 conversations.

<ParamField path="limit" type="integer" default="20">
  Maximum conversations to return. Minimum 1, maximum 200.
</ParamField>

<ParamField path="offset" type="integer" default="0">
  Conversations to skip, for paging.
</ParamField>

Available on: local, bridge, remote. Read-only.

### conversation

A conversation's latest messages in chronological order; does not mark them read. Use when the user says "read a conversation". Instead: messages for conversation ids. Input: conversation_id, limit and offset (from newest). Then: increase offset for older messages. Cost: 50 messages by default.

<ParamField path="conversation_id" type="integer" required>
  Conversation id, from `messages`.
</ParamField>

<ParamField path="limit" type="integer" default="50">
  Maximum messages to return. Minimum 1, maximum 200.
</ParamField>

<ParamField path="offset" type="integer" default="0">
  Messages to skip, counted from the newest.
</ParamField>

Available on: local, bridge, remote. Read-only.

### calendar

All course, user and site calendar events in the date window. Use when the user says "calendar events". Instead: due for actionable deadlines. Input: days and optional unit. Then: item for an activity. Cost: one page plus one view per month.

<ParamField path="days" type="integer" default="14">
  Window size in days. Minimum 1, maximum 365.
</ParamField>

<ParamField path="unit" type="string | integer">
  Unit code, name, id or URL. Omit to cover every enrolled unit.
</ParamField>

Available on: local, bridge, remote. Read-only.
