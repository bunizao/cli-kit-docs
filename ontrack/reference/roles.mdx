```bash
ontrack roles [options] [command]
```

## ontrack roles list

```bash
ontrack roles list [options]
```

**Options**

| Flags | Description |
| --- | --- |
| `--all` | Include inactive roles |

Global options apply to every command. See [Global options](/ontrack/reference/index#global-options).
