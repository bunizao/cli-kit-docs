---
title: "ontrack doctor"
description: "Diagnose authentication, cache, browser, and site discovery"
sidebarTitle: "doctor"
---

```bash
ontrack doctor [options]
```

**Options**

| Flags | Description |
| --- | --- |
| `--live` | Also verify a protected OnTrack endpoint |
| `--cookies` | Also probe existing browser cookies and report access problems |

Global options apply to every command. See [Global options](/ontrack/reference/index#global-options).
