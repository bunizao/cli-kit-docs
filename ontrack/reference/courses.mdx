```bash
ontrack courses [options] [command]
```

**Aliases:** `units`, `projects`

## ontrack courses list

```bash
ontrack courses list [options]
```

**Options**

| Flags | Description |
| --- | --- |
| `--include-inactive` | Include past units |

## ontrack courses show

```bash
ontrack courses show [options] <unit>
```

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `unit` | Yes | Unit code, name or project id |

## ontrack courses get

```bash
ontrack courses get [options] <unit>
```

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `unit` | Yes | Unit code, name or project id |

**Options**

| Flags | Description |
| --- | --- |
| `--dest <path>` | Destination ZIP |
| `--force` | Replace an existing destination |

Global options apply to every command. See [Global options](/ontrack/reference/index#global-options).
