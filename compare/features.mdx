This table lines up every command and MCP (Model Context Protocol) tool across the three CLIs, so you can see what each one covers at a glance. Every cell names the command or MCP tool that provides the capability, or `—` when that CLI doesn't have one. Rows come from what at least one of the three CLIs does; a `—` means that product's platform either doesn't have the concept or the CLI doesn't cover it yet, not that the row is wrong for that product. See [Web coverage](/compare/web-coverage) for how each of these compares to what the platform's own web UI offers.
