---
title: "edstem units"
description: "List or show enrolled units."
sidebarTitle: "units"
---

```bash
edstem units [options] [command]
```

**Aliases:** `courses`, `projects`

## edstem units list

```bash
edstem units list [options]
```

**Options**

| Flags | Description |
| --- | --- |
| `--archived` | Include archived units. |

## edstem units show

```bash
edstem units show [options] <unit>
```

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `unit` | Yes | Unit ID or code |

Global options apply to every command. See [Global options](/edstem/reference/index#global-options).
