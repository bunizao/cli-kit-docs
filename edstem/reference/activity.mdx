---
title: "edstem activity"
description: "List current-user activity."
sidebarTitle: "activity"
---

```bash
edstem activity [options] [unit]
```

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `unit` | No | Unit ID or code |

**Options**

| Flags | Description |
| --- | --- |
| `-n, --max <count>` | Maximum activity items |
| `-f, --filter <type>` | Activity type |

Global options apply to every command. See [Global options](/edstem/reference/index#global-options).
