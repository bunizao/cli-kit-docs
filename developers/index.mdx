This tab is for script authors, agent or integration builders, and contributors — anyone writing code against `moodle`, `edstem` or `ontrack` instead of typing commands at a keyboard. If you're a student or tutor looking to install a CLI, sign in, or connect an AI app, start at the [home page](/index) instead.
