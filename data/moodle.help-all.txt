$ moodle --help
moodle v0.12.0
Read Moodle and submit work from the command line

Usage
  moodle [options] [command] [target...]

Arguments
  target  Unit name, section, item phrase, or Moodle URL

Core commands
  due [unit]                  Items due in a date window
  news [unit]                 Latest announcement threads with first-post text
  find <query> [unit]         Ranked sections, activities and discussion
                              subjects
  open <ref>                  Open a unit or activity reference in the browser
  submit <ref> [files...]     Upload files into an assignment
  submission                  Read or remove your assignment submission
  complete <ref>              Mark an activity complete manually
  quiz                        Take a quiz (beta)
  courses, units, projects    Inspect enrolled units
  activities                  Inspect activities
  grades                      Inspect grades
  threads                     Inspect forum discussion threads
  forums                      Inspect forums

Additional commands
  sync [unit]                 Mirror units into local folders
  user                        Show authenticated user info
  todo                        List upcoming actionable timeline items
  alerts                      List notifications and message counts
  messages                    Read and send direct or group messages
  calendar                    All course, user and site calendar events in the
                              date window
  overview                    Show a compact multi-source overview
  download, dl, get [ref...]  Download files: one activity, a whole section, or
                              a file URL. With no argument, browse.
  auth                        Session and keepalive utilities
  doctor                      Diagnose runtime, session and MCP setup
  coverage                    Check which commands work on this site
  completion <shell>          Print shell completion for zsh, bash or fish
  uninstall                   Remove background jobs, Worker and config

Agent commands
  mcp                         Private MCP server on Cloudflare
  commands                    Describe the complete command tree
  skills                      Agent skill metadata

Commands
  attempt <ref>               Each question with your response, and mark,
                              correct answer and feedback when the site shows
                              them
  update                      Update the package and redeploy the managed MCP
                              Worker when either is behind

Options
  -V, --version        Show the version
  --json               Emit JSON
  --yaml               Emit YAML
  --table              Emit a human-readable table
  --fields <fields>    Select top-level fields
  -o, --output <file>  Write output to a file
  -v, --verbose        Enable debug logging
  --no-color           Disable color output
  -y, --yes            Confirm mutations non-interactively
  --dry-run            Print the mutation plan without applying it
  --no-cache           Bypass session cache reads and writes
  --pretty             Indent JSON output
  --limit <number>     Maximum returned rows
  --days <number>      Deadline window in days
  -h, --help           Show help

Try
  moodle  # today: due items, alerts and news
  moodle UNIT grades
  moodle submit UNIT "Assignment 2" report.pdf

Run 'moodle <command> --help' for details on a command.

$ moodle quiz --help
moodle quiz
Take a quiz: start an attempt, answer questions, finish it. Beta.

Usage
  moodle quiz [options] [command]

Commands
  start <ref>                                  Start a new attempt, or continue the one in progress, and show its first page
  show <attempt> <quiz>                        Show one page of an attempt in progress: questions, options and saved answers
  answer <attempt> <quiz> <question> [answer]  Save an answer: choice letters (b or a,c) or text
  finish <attempt> <quiz>                      Submit the attempt for grading. Moodle does not allow undoing this.

Global options
  --json, --yaml, --table, --fields <fields>, --output <file>, --verbose,
  --no-color, --yes, --dry-run, --no-cache, --pretty, --limit <number>,
  --days <number>

Run 'moodle quiz <command> --help' for details on a command.

moodle quiz is beta: it replays the browser's quiz forms, and a Moodle update can break it without warning.
Academic integrity: answers you send are your own submission under your institution's rules. Only use this
where the quiz allows it, and check the attempt in a browser before you finish.
