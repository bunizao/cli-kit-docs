$ edstem --help
edstem v0.7.0
Read and post on Ed Discussion from the command line

Usage
  edstem [options] [command]

Core commands
  threads                   List, search, show, or read Ed threads
  replies                   Post replies to Ed threads
  lessons                   List, show, read, or mark lessons as read
  slides                    Show, read, or submit lesson slides
  files                     List or download Ed-hosted lesson and thread files
  units, courses, projects  List or show enrolled units

Additional commands
  user                      Show the current Ed identity and enrolled units
  activity [unit]           List current-user activity
  auth                      Manage Ed authentication
  update                    Report or install the latest edstem-cli release

Agent commands
  commands                  Describe the complete command tree
  skills                    Generate the agent skill

Options
  -V, --version        Show the version
  --json               Emit JSON
  --yaml               Emit YAML
  --table              Emit a human-readable table
  --fields <fields>    Select top-level fields
  -o, --output <file>  Write output to a file
  --verbose            Enable debug logging
  --no-color           Disable color output
  -y, --yes            Confirm mutations non-interactively
  --dry-run            Print the mutation plan without applying it
  -h, --help           Show help

Try
  edstem threads UNIT  # latest threads in a unit
  edstem threads read UNIT#42
  edstem threads send UNIT --title "Week 3 question"  # asks for the body in $EDITOR

Run 'edstem <command> --help' for details on a command.

                               may remain first (choices: "new", "old", "top",
                               "hot", default: "new")
  -c, --category <category>    Filter by exact top-level category
  --subcategory <subcategory>  Filter by exact second-level subcategory
  -t, --type <type>            Filter by thread type
  --answered                   Only answered threads
  --unanswered                 Only unanswered threads
  --offset <count>             Skip this many threads before filtering (default:
                               0)
  --since <when>               Only threads created at or after an ISO date or a
                               relative offset such as 7d
  -h, --help                   Show help

  --no-color, --yes, --dry-run
