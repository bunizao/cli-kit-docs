$ ontrack --help
ontrack v0.3.2
Work with OnTrack tasks and chats from the command line

Usage
  ontrack [options] [command]

Core commands
  units, courses, projects  Enrolled units
  tasks                     Tasks in a unit: list, read, submit, set state
  chats                     Read and send task chat messages

Additional commands
  user                      Show the signed-in user
  roles                     Teaching roles you hold
  auth                      Manage authentication

Agent commands
  commands                  Describe the complete command tree
  skills                    Generate the agent skill

Options
  -V, --version        Show the version
  --json               Emit JSON
  --yaml               Emit YAML
  --table              Emit a human-readable table
  --fields <fields>    Select top-level fields
  -o, --output <file>  Write output to a file
  --verbose            Enable debug logging
  --no-color           Disable color output
  -y, --yes            Confirm mutations non-interactively
  --dry-run            Print the mutation plan without applying it
  -h, --help           Show help

Try
  ontrack tasks UNIT  # every task with its status and due date
  ontrack tasks read UNIT 1.1  # the task sheet as Markdown
  ontrack tasks submit UNIT 1.1 report.pdf

Run 'ontrack <command> --help' for details on a command.
