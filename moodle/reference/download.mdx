---
title: "moodle download"
description: "Download files: one activity, a whole section, or a file URL. With no argument, browse."
sidebarTitle: "download"
---

```bash
moodle download [options] [ref...]
```

**Aliases:** `dl`, `get`

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `ref...` | No | Activity id, same-site activity/section/file URL, or UNIT TASK phrase |

**Options**

| Flags | Description |
| --- | --- |
| `--to <directory>` | Destination directory; created when missing. |
| `--dest <path>` | Exact path for a single downloaded file. |
| `--force` | Atomically replace existing files. |

Global options apply to every command. See [Global options](/moodle/reference/index#global-options).
