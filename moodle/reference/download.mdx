---
title: "moodle download"
description: "Download one authenticated Moodle file."
sidebarTitle: "download"
---

```bash
moodle download [options] <source>
```

**Aliases:** `dl`

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `source` | Yes | Course-module ID or authenticated Moodle file URL |

**Options**

| Flags | Description |
| --- | --- |
| `--dest <path>` | Exact downloaded file path |
| `--force` | Atomically replace an existing destination |

Global options apply to every command. See [Global options](/moodle/reference/index#global-options).
