---

```bash
moodle overview [options]
```

**Options**

| Flags | Description |
| --- | --- |
| `--todo-limit <number>` | Maximum number of todo items. |
| `--todo-days <number>` | Only include todo items due within the next N days. |
| `--alerts-limit <number>` | Maximum number of notifications. |

Global options apply to every command. See [Global options](/moodle/reference/index#global-options).
