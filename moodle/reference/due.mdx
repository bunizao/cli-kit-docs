---
title: "moodle due"
description: "Items due in a date window."
sidebarTitle: "due"
---

```bash
moodle due [options] [unit]
```

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `unit` | No | Unit code, name, id or URL |

Global options apply to every command. See [Global options](/moodle/reference/index#global-options).
