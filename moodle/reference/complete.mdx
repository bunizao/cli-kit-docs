---
title: "moodle complete"
description: "Mark an activity complete manually."
sidebarTitle: "complete"
---

```bash
moodle complete [options] <ref>
```

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `ref` | Yes | Activity id, URL or UNIT TASK phrase |

**Options**

| Flags | Description |
| --- | --- |
| `--undo` | Mark the activity incomplete. |

Global options apply to every command. See [Global options](/moodle/reference/index#global-options).
