`moodle` v0.9.2 — Read Moodle and submit work from the command line.

## Global options

These options work on every command; command pages only list the options specific to that command.

| Flags | Description |
| --- | --- |
| `-V, --version` | Show the version |
| `--json` | Emit JSON |
| `--yaml` | Emit YAML |
| `--table` | Emit a human-readable table |
| `--fields <fields>` | Select top-level fields |
| `-o, --output <file>` | Write output to a file |
| `-v, --verbose` | Enable debug logging |
| `--no-color` | Disable color output |
| `-y, --yes` | Confirm mutations non-interactively |
| `--dry-run` | Print the mutation plan without applying it |
| `--no-cache` | Bypass session cache reads and writes |
| `--pretty` | Indent JSON output |
| `--limit <number>` | Maximum returned rows |
| `--days <number>` | Deadline window in days |
| `-h, --help` | Show help |

For what each exit code means, see [Errors and exit codes](/concepts/errors-and-exit-codes).
