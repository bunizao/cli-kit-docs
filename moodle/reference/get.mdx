---
title: "moodle get"
description: "Download a resource by id, URL, or UNIT TASK phrase."
sidebarTitle: "get"
---

```bash
moodle get [options] <ref>
```

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `ref` | Yes | Resource id, URL, or UNIT TASK phrase |

**Options**

| Flags | Description |
| --- | --- |
| `--to <directory>` | Destination directory. |
| `--force` | Replace an existing file atomically. |

Global options apply to every command. See [Global options](/moodle/reference/index#global-options).
