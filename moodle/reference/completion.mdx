---
title: "moodle completion"
description: "Print shell completion for zsh, bash or fish."
sidebarTitle: "completion"
---

```bash
moodle completion [options] <shell>
```

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `shell` | Yes | Shell to target |

Global options apply to every command. See [Global options](/moodle/reference/index#global-options).
