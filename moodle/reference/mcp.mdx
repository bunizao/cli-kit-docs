```bash
moodle mcp [options] [command]
```

## moodle mcp deploy

```bash
moodle mcp deploy [options]
```

**Options**

| Flags | Description |
| --- | --- |
| `--repair` | Repair authentication and managed deployment state. |
| `--rotate-key` | Rotate the session encryption key and migrate the active session. |
| `--rotate-token` | Rotate the MCP access token with an overlap window. |
| `--rollback` | Restore the previous healthy Worker release. |

<Warning>
This command changes data on the server. It asks for confirmation unless you pass `--yes`. Add `--dry-run` to print the plan without applying it.
</Warning>

```bash

```

| Argument | Required | Description |
