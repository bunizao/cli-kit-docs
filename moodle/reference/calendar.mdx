---
title: "moodle calendar"
description: "All course, user and site calendar events in the date window."
sidebarTitle: "calendar"
---

```bash
moodle calendar [options]
```

**Options**

| Flags | Description |
| --- | --- |
| `--unit <unit>` | Only events for this unit. |
| `--ics` | Export an iCalendar file to stdout or --output. |

Global options apply to every command. See [Global options](/moodle/reference/index#global-options).
