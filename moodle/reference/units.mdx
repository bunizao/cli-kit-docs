---
title: "moodle units"
description: "Inspect enrolled units."
sidebarTitle: "units"
---

```bash
moodle units [options] [command]
```

**Aliases:** `courses`

## moodle units list

```bash
moodle units list [options]
```

## moodle units show

```bash
moodle units show [options] <unit>
```

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `unit` | Yes | Unit ID or unique name |

Global options apply to every command. See [Global options](/moodle/reference/index#global-options).
