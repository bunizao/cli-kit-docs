---
title: "moodle skills"
description: "Show skill metadata or delegate to the shared skills CLI."
sidebarTitle: "skills"
---

```bash
moodle skills [options] [command]
```

## moodle skills generate

```bash
moodle skills generate [options]
```

## moodle skills add

```bash
moodle skills add [options]
```

Global options apply to every command. See [Global options](/moodle/reference/index#global-options).
