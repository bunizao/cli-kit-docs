---
title: "moodle courses"
description: "Inspect enrolled units."
sidebarTitle: "courses"
---

```bash
moodle courses [options] [command]
```

**Aliases:** `units`, `projects`

## moodle courses list

```bash
moodle courses list [options]
```

## moodle courses show

```bash
moodle courses show [options] <unit>
```

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `unit` | Yes | Unit ID or unique name |

Global options apply to every command. See [Global options](/moodle/reference/index#global-options).
