---
title: "moodle open"
description: "Open a unit or activity reference in the browser."
sidebarTitle: "open"
---

```bash
moodle open [options] <ref>
```

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `ref` | Yes | Unit or activity id, URL, or UNIT TASK phrase |

Global options apply to every command. See [Global options](/moodle/reference/index#global-options).
