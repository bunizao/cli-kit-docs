```bash

```

## moodle grades list

```bash
moodle grades list [options] [unit]
```

**Arguments**

| Argument | Required | Description |
| --- | --- | --- |
| `unit` | No | Unit code, name, id or URL |

**Options**

| Flags | Description |
| --- | --- |
| `--mode <mode>` | graded (default), summary or all. |
| `--types <types>` | Comma-separated module types (assign, quiz, h5pactivity). |
| `--include-feedback` | Include full grader feedback. |
| `--include-ungraded` | Include ungraded items in graded mode. |
| `--offset <number>` | Skip this many matching rows. |
| `--graded-only` | Alias for --mode graded. |

Global options apply to every command. See [Global options](/moodle/reference/index#global-options).
